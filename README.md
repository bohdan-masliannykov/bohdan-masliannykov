<a href="https://resumetyper.app">

<img src="https://img.shields.io/badge/status-public%20beta-16A34A?style=flat-square" alt="Status: public beta">

A privacy-first resume builder that I designed, built and operate end to end – from product concept and UX to development, deployment and production infrastructure.

- **Live PDF preview** – the page updates as the user types; rendering runs in a Web Worker with page caching, so the interface stays responsive
- **Privacy by design** – no accounts, no analytics and no tracking; resumes are stored in the browser and portable as a JSON backup
- **CV import** – an existing resume can be imported and sorted into structured fields, without the text being stored
- **Quality guidance** – a 0–100 completeness score with writing tips for each section
- **ATS-readable templates** – 30 templates in six families with selectable text in a single reading order
- **Multilingual** – resumes in English, Polish, German and Ukrainian
- **Production infrastructure** – self-managed VPS behind Cloudflare with transactional email; payment integration in progress

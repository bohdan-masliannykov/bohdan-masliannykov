## Bohdan Masliannykov

Senior Frontend Engineer with 9 years of experience delivering web applications in React, Angular and TypeScript. My work centres on frontend architecture, performance and accessibility, and I apply AI-assisted development to accelerate delivery while maintaining high engineering standards.

### Current project

**[resumetyper](https://resumetyper.app)** – a privacy-first resume builder, currently in public beta.
All data remains on the user's device: resumes are stored locally and rendered to PDF within a Web Worker, keeping the interface responsive during rendering. No account is required and no tracking is used.
